# T16XE — 16-битный эмулятор процессора и тулчейн

Полностью самописный эмулятор 16-битного процессора на C++17 с собственным набором инструкций, ассемблером, бинарным форматом исполняемых файлов и графическим отладчиком. Создан как образовательная и экспериментальная платформа для низкоуровневого программирования.

## ⚠️ В разработке

Эмулятор всё ещё активно развивается. Прямо сейчас идёт масштабный рефакторинг ядра для исправления известных багов, повышения стабильности и подготовки к первому релизу.

Что может пойти не так прямо сейчас:
- Некоторые инструкции отсутствуют или работают некорректно.
- Прерывания и порты ввода-вывода стабилизируются — ввод с клавиатуры может работать не так, как ожидается.
- Программы, которые работают сегодня, могут сломаться после обновления.
- Возможны падения, зависания или неожиданное поведение.

Если что-то не работает, пожалуйста, сообщите об этом в [Issues](https://github.com/torutos/tpf-t16xe/issues).

## Возможности

### Эмулятор процессора
- 32 МБ адресуемой памяти
- 5 регистров общего назначения (16 бит): AX, BX, CX, DX, SP
- Сегментные регистры: CS (код), DS (данные), SS (стек)
- Флаги: Carry (C), Zero (Z), Negative (N), Overflow (O), Interrupt Disable (I)
- Аппаратные прерывания (клавиатура через порты 0xFFF0/0xFFF1)
- Программные прерывания (инструкция INT, таблица векторов по адресу 0x10000-0x103FF)
- Операции со стеком (PUSH, POP, CALL, RET — поддерживаются дальние вызовы)
- Порты ввода-вывода для вывода символов (0x1FFFFF2)

### Ассемблер (TASM)
- Двухпроходный ассемблер с разрешением меток
- Макросы с параметрами (`%macro`, `%1`, `%2`)
- Константы EQU с подстановкой выражений
- Локальные метки (начинаются с `.`)
- Директива `times` для повторений
- `%include` для многофайловых проектов
- Директивы данных: `db`, `dw`, `ds`, `resb`, `resw`, `fill`
- Секции: `.data` и `.code`
- Собственный бинарный формат `.toru` с заголовком (размер данных, размер кода, адрес загрузки)

### Графическая студия (TPSGUI)
- Написана на ImGui и GLFW
- Редактор кода с подсветкой синтаксиса (TextEditor)
- Просмотр регистров (AX, BX, CX, DX, SP, PC, флаги)
- Просмотр дампа памяти (hex + ASCII)
- Брейкпоинты (добавление/удаление/очистка, пауза при срабатывании)
- Управление выполнением: Step / Run / Stop
- Панель вывода терминала
- Работа с файлами: Open, Save, Save As через нативные диалоги

### CLI-тулчейн
- Одна команда: `t16xe program.tsm` — валидация, сборка и запуск
- Поддержка callback'ов вывода для кастомных фронтендов
- Поддержка callback'ов ввода для программ с клавиатурным управлением

## Документация и разработка

Мы начали улучшать документацию проекта, чтобы было проще понимать его, контрибьютить и отслеживать прогресс.

- **`docs/`** — Документация проекта, заметки по дизайну и архитектурные решения.
- **`docs/TODO.md`** — Известные баги, запланированные фичи и технический долг.
- **`docs/opcodes.md`** — Справочник по набору инструкций и карта опкодов.
- **Исправления и история** — Мы активно чиним баги ядра (симметрия стека, дальние вызовы, обновление флагов). История коммитов и список `TODO` — основные источники правды о том, что уже исправлено, а что ещё в планах.

*(Более детальные дизайн-документы будут добавлены по мере продвижения рефакторинга.)*

## Сборка

```bash
cmake -B build
cmake --build build
```

Требования: C++17, CMake 3.16+, OpenGL (для GUI). Все зависимости (ImGui, GLFW) подтягиваются автоматически.

## Использование

```bash
# CLI: сборка и запуск
t16xe program.tsm

# GUI: Toru Processor Studio
tpsgui
```
