# T16XE — Эмулятор 16-битного процессора и инструментарий

Полностью самодельный 16-разрядный процессор, написанный на C++17, с собственным набором инструкций, ассемблером, бинарным форматом исполняемых файлов и графическим отладчиком. Проект создан как образовательная и экспериментальная платформа для низкоуровневого программирования.

## ⚠️ Проект в разработке

Эмулятор всё ещё активно дорабатывается. Что может пойти не так:

- Некоторые инструкции отсутствуют или работают некорректно.
- Прерывания и порты ввода-вывода подключены не полностью — ввод с клавиатуры может работать нестабильно.
- Программы, которые работают сегодня, могут сломаться после обновления.
- Возможны вылеты, зависания и неожиданное поведение.

Эти проблемы постепенно решаются. Основная цель перед первым релизом — стабилизировать набор инструкций и завершить подсистему ввода-вывода.

Если что-то не работает — сообщите в [Issues](https://github.com/torutos/tpf-t16xe/issues). Если хотите дождаться стабильной версии — первый релиз уже на подходе.

## Возможности

### Эмулятор процессора
- 1 МБ адресуемой памяти
- 5 регистров общего назначения (16 бит): AX, BX, CX, DX, SP
- Сегментные регистры: CS (код), DS (данные), SS (стек)
- Флаги: Carry (C), Zero (Z), Negative (N), Overflow (O), Interrupt Disable (I)
- Аппаратные прерывания (клавиатура через порты 0xFFF0/0xFFF1)
- Программные прерывания (INT, таблица векторов 0x0000-0x03FF)
- Стековые операции (PUSH, POP, CALL, RET)
- Порты ввода-вывода (вывод символа через 0xFFF2)

### Ассемблер (TASM)
- Двухпроходный ассемблер с разрешением меток
- Макросы с параметрами (`%macro`, `%1`, `%2`)
- Константы EQU с подстановкой выражений
- Локальные метки (начинаются с `.`)
- Директива `times` для повторения инструкций
- `%include` для многофайловых проектов
- Директивы данных: `db`, `dw`, `ds`, `resb`, `resw`, `fill`
- Секции: `.data` и `.code`
- Собственный бинарный формат `.toru` с заголовком (размер данных, размер кода, адрес загрузки)

### GUI Studio (TPSGUI)
- Интерфейс на ImGui и GLFW
- Редактор кода с поддержкой синтаксиса (TextEditor)
- Просмотр регистров (AX, BX, CX, DX, SP, PC, флаги)
- Дамп памяти (hex + ASCII)
- Точки останова (добавление/удаление/очистка, остановка при достижении)
- Пошаговое выполнение / Запуск / Остановка
- Панель вывода терминала
- Файловые операции: Открыть, Сохранить, Сохранить как через системные диалоги

### CLI
- Одна команда: `t16xe program.tsm` — валидация, сборка и запуск
- Поддержка callback-функций вывода для пользовательских интерфейсов
- Поддержка callback-функций ввода для программ с клавиатурой

## Сборка

```bash
cmake -B build
cmake --build build
```

Требования: C++17, CMake 3.16+, OpenGL (для GUI). Все зависимости (ImGui, GLFW) загружаются автоматически.

Использование

```bash
# CLI: сборка и запуск
t16xe program.tsm

# GUI: Toru Processor Studio
tpsgui
```

Пример программы (Hello World)

```asm
org 0x0400

section .data
msg: ds "Hello World"

section .code
start:
    MOV BX, #msg        ; загружаем адрес строки
.loop:
    LDB AX, [BX]        ; загружаем байт
    CMP AX, #0          ; проверяем на конец строки
    JEQ .done
    STB [0xFFF2], AX    ; выводим символ
    INC BX
    JMP .loop
.done:
    HLT
```

Структура проекта

```
tpf-t16xe/
├── t16xe/src/kernel/       # Ядро эмулятора
├── t16xe/src/asm/          # Ассемблер
├── gui/                    # GUI Studio (ImGui + GLFW)
│   ├── panels/             # Панели: редактор, эмулятор, регистры, память
│   └── libs/               # Сторонние библиотеки
└── tcc/                    # Компилятор (в планах)
```
