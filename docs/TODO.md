### execute.cpp (ядро)
- [x] **MOV трогает флаги.** Убрать `update_flags` из всех `MOV_*` (`REG_IMM`, `REG_REG`, `REG_MEM`, `REG_MEMREG`, `REG_SEG`). Перемещение не меняет флаги.

- [ ] **CALL/RET: CS теряет старший байт.** `CALL` сохраняет 2 байта `CS`, `RET` читает 1 байт. Исправить: `CS = memory[addr] | (memory[addr+1] << 8)`.
- [ ] **PUSHF/POPF: потеря старшего байта.** `PUSHF` кладёт 2 байта, `POPF` читает 1. Исправить на `uint16_t`.
- [ ] **SOFTWARE_INT/IRET: потеря CS и флагов.** `INT` кладёт по 2 байта, `IRET` читает по 1. Исправить.
- [ ] **SHL/SHR: UB при shift == 0.** `1 << (16 - shift)` и `1 << (shift - 1)`. Добавить `if (shift > 0)`, иначе `flagC = false`.
- [ ] **DEC_REG: инвертированный flagC.** Привести к единому смыслу с `SUB`/`CMP`.
- [ ] **SUB_REG_REG не выставляет flagO.** Добавить вычисление переполнения, как в `ADD`.
- [ ] **ADD/SUB_REG_IMM не выставляют flagO.** Добавить.
- [ ] **ADD/ADC/SBB: сравнение на int-промоушене.** `result < a` может врать. Явно приводить к `uint16_t`.
- [ ] **JMP/CALL: обрезка 32-битного адреса в 16-битный PC.** Решить: ограничить `off` или обрабатывать сегмент.
- [ ] **MOV_SEG_REG / MOV_REG_SEG: switch без default.** Добавить `default:` с ошибкой.
