# TODO — Toru16 / t16xe / tasm

## P0 — Блокеры (баги, которые ломают корректность)

### 1. Ядро: Адресация и память (фундамент)
- [ ] **phys_addr: нет проверки границ.** `(seg << 16) | offset` может выйти за 32 МБ → segfault.
- [ ] **phys_addr: мёртвый `if`.** `if (addr >= 0x1FFFFF0) return addr;` ничего не делает. Убрать или сделать обработку портов.
- [ ] **reset(): вектор сброса (0x1FFFFF4) неверен.** Там лежит адрес кода (из app.hpp), а не `CS:PC`. Проверить, что именно кладется в память при загрузке.
- [ ] **reset(): UB при сдвиге.** `memory[vec+1] << 8` — это `int`, может дать отрицательное значение. Явно приводить к `uint32_t`.
- [ ] **phys_addr static:** не видит `MEMORY_SIZE`. Решить, где проверять границы (внутри или во всех вызовах).

### 2. Ядро: Декодирование и регистры
- [ ] **decode_reg: нет проверки reg < 5.** Неизвестный регистр → тихий сбой.
- [ ] **write_reg/read_reg: default молчит.** Логировать ошибку или падать, а не делать вид, что всё ок.
- [ ] **decode_imm32 в MOV_REG_IMM.** Комментарий говорит `#imm16`, а читается 32 бита (съедает лишние 2 байта кода). Проверить и исправить.

### 3. Ядро: Флаги и арифметика
- [x] **MOV трогает флаги.** Убрать `update_flags` из всех `MOV_*`. Перемещение не меняет флаги.
- [x] **LDB трогает флаги, STB — нет.** Асимметрия. Убрать `update_flags` из `LDB_REG_MEM` и `LDB_REG_MEMREG`.
- [ ] **AND_REG_REG/OR_REG_REG/XOR_REG_REG: нет сброса C и O.** (В версиях IMM сброс есть, в REG_REG — нет).
- [ ] **DEC_REG: инвертированный flagC.** Привести к единому смыслу с `SUB`/`CMP`.
- [ ] **SUB_REG_REG не выставляет flagO.** Добавить вычисление переполнения, как в `ADD`.
- [ ] **ADD/SUB_REG_IMM не выставляют flagO.** Добавить.
- [ ] **ADD/ADC/SBB: сравнение на int-промоушене.** `result < a` может врать. Явно приводить к `uint16_t`.

### 4. Ядро: Стек и подпрограммы
- [ ] **CALL/RET: гибрид ближнего и дальнего вызова.**
  - CALL сохраняет CS (как дальний), но прыгает линейно (как ближний).
  - RET читает CS как 1 байт (баг).
  - **Решение:** Сделать CALL дальним. `off` = `CS:PC` (32 бита). CALL сохраняет старый CS+PC, ставит новые. RET читает PC (2 байта), потом CS (2 байта).
- [x] **PUSHF/POPF: потеря старшего байта.** POPF читает 1 байт вместо 2. Исправить на `uint16_t`.
- [x] **SOFTWARE_INT/IRET: потеря CS и флагов.** INT кладёт по 2 байта, IRET читает по 1. Исправить.

### 5. Ядро: Прерывания и Отладчик (step)
- [ ] **step: new_cs читается 1 байт вместо 2.** (Асимметрия с execute).
- [ ] **step: memory[addr] = CS.** 16 бит пишутся в 1 байт (теряется старший).
- [ ] **step: таблица векторов 0x10000 + 9*4.** В execute — `vector * 4`. Свести к одной базе.
- [ ] **step: прерывание проверяется до execute.** Может прервать инструкцию на середине. Проверять после (или между).
- [ ] **step: брейкпоинт проверяется после PC++.** Срабатывает на следующей инструкции, а не на текущей.
- [ ] **step: return false не различает HLT и брейкпоинт.** Отладчик не поймет, почему встал.
- [ ] **step: input_callback вызывается каждый шаг.** Может терять ввод. Проверять флаг `memory[0xFFF0] & 1` перед записью.

### 6. Ядро: Сдвиги и переходы
- [ ] **SHL/SHR: UB при shift == 0.** `1 << (16 - shift)` и `1 << (shift - 1)`. Добавить `if (shift > 0)`, иначе `flagC = false`.
- [ ] **JMP/CALL: обрезка 32-битного адреса в 16-битный PC.** Решить, как работает переход (линейно или сегментно).

### 7. Ядро: Мелочи
- [ ] **MOV_SEG_REG / MOV_REG_SEG: switch без default.** Добавить обработку ошибки.
- [ ] **SP = 0xFEEF (reset/execute) vs 0xFEFF (BIOS).** Привести к одному значению.

### 8. Диск (app.hpp)
- [ ] **loadFromDisk: нет проверки границ.** `offset + size > diskSize` → выход за границу.
- [ ] **writeFileToDisk: нет проверки свободного места.** Файл может перезаписать данные.
- [ ] **Убрать/ограничить хост-доступ в write** перед релизом.
